Go to the Shared Component --> Files and Reports --> Report Queries 

Step 1: Click the Create Button 
	Report Query Name: EMPLOYEE_APPOINTMENT_LETTER
Click Next
	Output Format: PDF
	View File as: Inline
Click Next
	Choose Source Type: SQL Query
	Enter Query:
	 select FIRST_NAME, LAST_NAME, EMAIL, PHONE, HIRE_DATE, SALARY from employees where emp_id=:P1_EMPLOYEE_ID
	
Click Next--> Click Next --> Finish



Step 2: Now Create a Blank Page.
	Name: Employee Report Print

Step 3: Create a Page item 
	Name: Employee Report Print
	Type: Select List
	List of values:
		SQL Query:
			SELECT FIRST_NAME || ' (' || LAST_NAME || ')' AS display_value,
     			EMP_ID AS return_value
			FROM employees
			ORDER BY FIRST_NAME	

Step 4: Create a Button
	Name: Get_Appointment_Letter
	Title: Get PDF Appointment Letter
	
Step 5: Create Triggered Action		
	Action: Execute JavaScript Code
	



// 1. Get the current page item value
var empId = apex.item("P2_EMPLOYEE_ID").getValue();

// 2. Build the correct Report Query URL syntax
var url = "f?p=&APP_ID.:0:&SESSION.:PRINT_REPORT=EMPLOYEE_APPOINTMENT_LETTER:::P1_EMPLOYEE_ID:" + encodeURIComponent(empId);

// 3. Open it in a new tab
apex.navigation.openInNewWindow(url);


Step 6: Now Run the Page. 
	Select the employee name from Lov and click button
